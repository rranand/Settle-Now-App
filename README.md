# settlenow

Need a way to split bills equally among friends/flatmates?
Then don't worry, we have a solution for you. Let's make it possible using "Settle Now".

Settle Now helps to split daily bills within your friends, roommates, flatmates, etc, and eliminate the stressing about “who owes who.”
By using the Settle Now, we can efficiently manage all costs per individual, track ‘who paid how much and ‘who should pay to whom’ via your mobile devices.


## Key Features:
1. Easy to use.
2. Create groups for any splitting situation.
3. Bills are backed-up online so anyone can log in, view their balances, and add expenses in the room.
4. Can track your personal expense and can categorise among different categories and can analyse using a graph.
5. Can check your previous expense, under the closed room section after everyone has paid the amount.
6. Profile photo.
7. Activity feed and push notifications to help you stay on top of changes.

## How to use Settle Now?
1. Simply login or register using your mail ID and an OTP.
2. Create your personalised room to split bills according to people and then send the room key to everyone, so that everyone could join the room.
3. After joining the room, every individual can add the amount they have spent with the purpose. And others would be able to see their equal share and amount they need to pay to whom.
